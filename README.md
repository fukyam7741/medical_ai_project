# Medical AI Project: 医疗智能问答与病历结构化系统

## 📌 项目简介
本项目是一套面向医疗辅助场景的**端到端AI应用**，集成三大核心功能模块，解决了大模型在专业场景下的幻觉与输出不稳定问题：

1.  **RAG 医疗知识库问答**
    - 基于权威医学文档构建向量知识库，实现领域知识可控
    - 可针对临床诊疗规范、慢病管理、健康咨询等专业问题提供循证解答
    - 避免大模型幻觉，严格依据知识库内容作答，保证专业性与安全性

2.  **病历结构化解析（硬编码兜底保障稳定）**
    - 支持从自由文本病历中抽取关键字段：年龄、性别、主诉、现病史、既往史、体征、检查结果、诊断、用药等
    - 双层架构：大模型智能抽取 + 硬编码规则兜底，彻底解决模型输出不稳定、回答跑偏问题
    - 自动生成标准化Excel表格，适配临床数据统计与录入场景

3.  **自由AI对话咨询**
    - 支持日常医学健康咨询，兼顾医学专业性与回答安全性
    - 提供友好、可交互的健康问答体验

---

## 🛠️ 技术栈
| 模块 | 核心技术 |
| :--- | :--- |
| RAG问答 | Python, LangChain, Chroma/FAISS 向量数据库, Sentence-BERT 向量模型 |
| 病历结构化 | 正则表达式（硬编码规则）, Pandas, Openpyxl |
| 对话引擎 | 大模型API调用 |

---

## ✨ 项目亮点
✅ **高可靠性**：病历结构化采用「大模型抽取 + 硬编码兜底」双保险，彻底解决模型不稳定问题  
✅ **知识可控**：RAG问答严格基于权威医学知识库，从源头避免大模型幻觉  
✅ **工程化落地**：直接支持Excel导出，适配临床数据整理场景，具备实际应用价值  
✅ **轻量化部署**：核心代码精简，依赖明确，无冗余配置
